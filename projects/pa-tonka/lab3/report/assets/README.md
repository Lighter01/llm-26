# Иллюстрации отчёта

Оригинальные снимки настоящего локального Langfuse 4.79.0, сделанные 13 ноября 2026 года. Они иллюстрируют сохранённую матрицу commit `7954685`; новых модельных ответов при подготовке отчёта не создавалось. Снимки получены браузером после входа в локальный проект, без генерации или реконструкции интерфейса.

Браузер отображал время `Europe/Moscow`. Для рисунка 3 использован непосредственный захват области окна; остальные снимки показывают viewport. Пиксели после съёмки не редактировались. Подписи и интерпретация чисел находятся в [отчёте](../LAB3_REPORT.md). Оригинал PNG можно открыть по ссылке в таблице и увеличить.

URL ведут в локальный Langfuse `http://127.0.0.1:3000` и требуют доступа к сохранённому проекту. Секреты входа и браузерный профиль в этот каталог не включены. Автоматические поля служебных Experiment observations не заменяют фактические метрики агента; это различие объяснено в отчёте.
