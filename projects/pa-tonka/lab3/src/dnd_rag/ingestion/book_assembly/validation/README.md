# Проверки исходников и полноты

`validate_assembly.mjs` независимо восстанавливает исходные главы, проверяет порядок, обязательные вставки, source locations и таблицы/изображения. `validate_enrichment.mjs` проверяет поля правил, дочерние компоненты, связность placements/shared content и решение по каждой source-defined записи.

Их вызывают assembly/enrichment и повторно финализация перед публикацией. Проверки готовой самодостаточной книги и manifest расположены рядом с контрактом в `resolution/`. Unit, native и сквозные регрессии находятся в `tests/ingestion/`.
