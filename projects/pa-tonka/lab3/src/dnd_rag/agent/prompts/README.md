# Инструкции агента

| Файл | Назначение |
| --- | --- |
| [system.txt](system.txt) | Общая предметная инструкция на английском для LangChain и developer instructions Codex: источники, выбор tools, уточнения, достоверность правил и фактической добычи. |
| [summary.txt](summary.txt) | Инструкция LLM для сводки всей заменяемой части истории: партия, ограничения, обязательные существа, принятые составы, фактическая добыча, сюжетные факты, источники и открытые вопросы. |

Промпты не содержат эталонов или ожидаемых ответов датасета. `summary.txt` получает сообщения в JSON через единственный шаблонный маркер `{messages}`; [memory.py](../memory.py) проверяет полный вход суммаризатора и допустимость результата перед заменой истории.

## Переносы строк

В TXT каждый обычный абзац записан одной физической строкой. Пустая строка отделяет смысловые абзацы; перенос перед `{messages}` отделяет инструкцию от JSON. Переносы внутри предложений здесь не несут специального смысла и напрямую попали бы во вход модели.

Описания tools находятся в [descriptions.yaml](../../tools/descriptions.yaml). YAML-маркер `>-` сворачивает обычные переносы внутри значения в пробелы; это отличается от TXT. Для удобства редактирования каждое описание также записано одной строкой. Изменение whitespace может менять токенизацию и fingerprint даже при сохранении слов; принадлежность измерений конкретной версии раскрыта в [отчёте](../../../../report/LAB3_REPORT.md).
