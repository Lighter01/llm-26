# Инструкции агента

`system.txt` — общая English предметная инструкция для LangChain и developer instructions Codex: границы источников/инструментов, уточнения, достоверность правил и фактической добычи. Prompt не содержит gold или ожидаемых ответов. `summary.txt` — structured English summary полного заменяемого prefix с проверкой собственного бюджета; сохраняет party/constraints/accepted encounters/actual loot/story facts/source references/open questions.
