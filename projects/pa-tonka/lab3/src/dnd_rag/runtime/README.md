# Управление локальным запуском

`index.py` отвечает за `ensure_index`, `prepare_retriever`, `reset_index`, запуск/reuse Qdrant и GPU build-worker. Worker полностью завершается перед возвратом; ready-reuse не загружает document encoder. `application.py` — общий lifecycle: infrastructure readiness → catalog/index → exited GPU worker → llama → MCP/proxy → CLI/runner. `application_stack` удерживает RuntimeSession; background services проверяют свободный порт и завершаются через try/finally. `llama.py` и `llm.py` содержат изолированные примитивы локальной LLM и не импортируются retrieval-ядром.

`processes.py` предоставляет `RuntimeSession`: одна блокировка проекта, наследование lock descriptor дочерними процессами, группы процессов и cleanup только принадлежащих запуску процессов. `lock.py` реализует блокировку; `preflight.py` различает отказ соединения и неопределённую сетевую ошибку. При timeout нельзя считать endpoint свободным. Контейнеры и их данные после выхода сохраняются.

На главном потоке RuntimeSession обрабатывает SIGINT/SIGTERM с выходом через cleanup. На время Popen/регистрации и самого cleanup обработка сигнала откладывается; ОС-маска ребёнка не блокирует TERM. Исходные handlers восстанавливаются после выхода. SIGKILL нельзя обработать: унаследованный lock остаётся у живого ребёнка. `owned_process_groups` проверяет живого лидера либо наследование именно открытого FLOCK; совпадение имени lock-файла или повторное использование PGID не даёт права завершать чужую группу.

`codex_proxy.py` — узкий loopback compatibility адаптер `8081/v1/responses` для установленного Codex 0.167: его additional_tools/namespace формат несовместим с llama build 11046. Схемы пяти MCP tools переносятся в root tools, имена преобразуются обратимо в histories/SSE; исходные сообщения и tool results сохраняются. Общий LLM profile задаёт thinking/output limit, native full-payload count проверяется с upstream usage. Original/effective bodies и ответы — `.runtime/codex-wire/<session>/wire.jsonl`. Агентный цикл и native compaction остаются внутри Codex.
