# Тесты валидатора вопросов

```bash
uv run --group test python -m pytest tests/ingestion/question_validation
```

Небольшие синтетические книги, карта и полный набор 23 записей создаются в pytest tmp. Проверяются строгая схема, типы и ID, alternatives, точный поиск, Unicode/LF, границы разделов, повторные пути, неоднозначность, отчёты, атомарная публикация, сохранность входов и предыдущего результата, CLI и воспроизводимость.

Реальные книги не нужны для этих тестов. Полный smoke на готовом корпусе описан в [README модуля](../../../src/dnd_rag/ingestion/question_validation/README.md). Тесты не запускают сборщик или экспортёр.
