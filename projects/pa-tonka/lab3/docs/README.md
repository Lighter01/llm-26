# Документация проекта

[Ingestion](ingestion/README.md) описывает готовую подготовку книг и вопросов: архитектуру, модель данных, сборку, Markdown и проверку. [README исходников](../src/dnd_rag/ingestion/README.md) — команды и навигация ingestion.

[Пользовательские руководства](user_docs/README.md) объясняют устройство RAG и работу с конвейером; проект реализован, руководства отражают текущие интерфейсы. Технические отчёты и измерения остаются отдельными документами, README модулей служат навигацией по исходникам.

[Проверки проекта](rag/VALIDATION.md) описывают повторяемые проверки, QA20, историческую приёмку и её ограничения. [Technical probes](rag/TECHNICAL_PROBES.md) — реальные версии, совместимость моделей/Qdrant и измерения.

[Эксперименты C4](rag/EXPERIMENTS.md) — 10 профилей, сводная CSV-таблица и обоснование выбора базовых конфигураций и профиля QA.

[Готовый отчёт](../report/LAB2_REPORT.md) объединяет постановку задачи, технические решения, шесть графиков и анализ результатов. [Дополнительные измерения](../results/technical/README.md) отделены от штатных runs и снабжены пояснениями метода.
