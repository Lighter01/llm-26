# Пользовательская документация

Система ищет правила в трёх книгах D&D, передаёт найденные фрагменты локальной Nemotron и показывает ответ с цитатами через FastAPI и Streamlit. Сохранены результаты первичной сборки и повторного использования индекса, 10 поисковых экспериментов и [финального прогона по 20 вопросам](../../results/qa_final/qa_summary.json). Код прошёл независимое ревью. [Agent-assisted рецензия QA20](../../results/qa_final/qa_review.csv) заполнена; [отчёт](../../report/LAB2_REPORT.md) готов. Исходная QA-сводка сохраняет состояние до рецензирования.

- [Устройство системы](ARCHITECTURE.md) — путь данных, основные Python-модули, два токенайзера, координаты цитат, правила повторного использования индекса и расчёт метрик.
- [Установка и CLI](CLI.md) — настройки `.env`, команды `build-index`, `reset-index`, `experiment`, `serve-retrieval`, `demo`, `evaluate-qa`, `summarize-results`, их флаги, результаты и диагностика.
- [Конфигурации](../../configs/experiments/README.md) — поля YAML экспериментов и карты сравнений, значения по умолчанию, допустимые значения и условия пересборки индекса.
- [Итоговая приёмка](../rag/VALIDATION.md) и [технические пробы](../rag/TECHNICAL_PROBES.md) — метрики, время выполнения, потребление ресурсов, версии и известные ограничения.

[Сравнение экспериментов](../rag/EXPERIMENTS.md) содержит результаты 10 запусков, показатели покрытия и ранговой позиции, затраты и обоснование выбора профиля для QA.

Для готовой подготовки данных доступны [документы ingestion](../ingestion/README.md) и [инструкция валидатора вопросов](../../src/dnd_rag/ingestion/question_validation/README.md). Навигация по исходникам — в [README пакета](../../src/dnd_rag/README.md).
