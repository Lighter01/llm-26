# Руководство

[CLI](CLI.md) описывает установку, настройки и все доступные команды. [Архитектура](ARCHITECTURE.md) объясняет путь данных, isolation и управление процессами. [Retrieval](../rag/README.md) содержит границы ядра и проверки. [Ingestion](../ingestion/README.md) — воспроизводимая подготовка книг.

Приложение запускает собственный LangChain агент с пятью MCP tools, памятью и native token guard; runner сравнивает его с Codex на тех же модели и инструментах. [Демонстрация](DEMO.md) описывает CLI, history update, compaction и Langfuse. [Отчёт](../../report/LAB3_REPORT.md) содержит фактические результаты и ограничения.

[EVALUATION.md](EVALUATION.md) — фиксированный dataset, методики, review worksheet и воспроизводимые артефакты.
